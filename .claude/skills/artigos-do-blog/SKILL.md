# Artigos do Guia Interativo

Guias longos sobre cortinas e persianas, assinados por um profissional que
atende presencialmente. O leitor chega com um problema concreto — o quarto
que clareia às cinco da manhã, o orçamento que veio três vezes mais caro
que o outro — e precisa sair sabendo o que fazer.

## O que decide se o texto presta

Cada seção precisa trazer algo que a pessoa **não saberia sem ler**. Se um
parágrafo pode ser substituído por "escolha um bom tecido", ele não deveria
existir. O critério é sempre: isso muda uma decisão de compra?

O que costuma render:

- um número que ninguém informa (a screen 1% a 3% na fachada oeste)
- uma consequência que só aparece depois (blackout revestido racha se for dobrado)
- um erro caro e comum (medir a janela e não o ponto de instalação)
- um mecanismo explicado (o vidro frio puxa calor do corpo; não é vento entrando)

## A régua da linguagem

Estes limites saem de uma auditoria de 78 textos deste blog, não de teoria.
Os problemas que mais denunciavam escrita de máquina não eram os clichês
óbvios — eram **frequências**, invisíveis num artigo lido sozinho.

| Padrão | Encontrado antes | Limite |
|---|---|---|
| Travessão em texto corrido | 21 por artigo | **até 6** |
| Fórmula "não é X, é Y" | 52 em 78 textos | **1 por artigo** |
| Conectivo formal ("Além disso", "Sobretudo") | — | **até 2** |
| Frase-gancho de fórmula | "A consequência prática:" em 14 artigos | **1, e variada** |

### O travessão é o pior deles

A pausa dramática antes do complemento é a assinatura mais reconhecível de
texto gerado em português. Na dúvida, use ponto: quase sempre lê melhor.

Ruim: `A janela é o ponto fraco — e é por ali que o calor entra.`
Bom: `A janela é o ponto fraco. É por ali que o calor entra.`

Guarde o travessão para aposto de verdade, com par: `o rapport — a distância
de repetição do desenho — encarece o corte`. Em tabela e lista ele é normal;
o limite vale só para texto corrido.

### A fórmula "não é X, é Y"

Corrigir uma crença errada assim funciona uma vez por texto. Repetida, vira
molde reconhecível.

Ruim: `Não é o tecido que isola — é o vazio dentro dele.`
Bom: `Quem isola é o vazio dentro do tecido.`

### As frases-gancho

Abrir parágrafo com um rótulo em negrito ajuda a escanear. O problema é
repetir o **mesmo** rótulo entre artigos. Varie: "Na prática:", "O que isso
muda:", "Traduzindo para a sua janela:", "O efeito disso:", "Onde isso
aparece:".

## O que nunca entra

Lista definida pelo dono do site. Zero tolerância, porque cada item denuncia
o texto sozinho:

**Aberturas** — "No mundo atual", "Nos dias de hoje", "É inegável que", "Não
é segredo que", "Vivemos em uma era", "Você já parou para pensar", "Imagine
só". Abra com uma situação que o leitor reconheça da própria casa.

**Conectivos** — "Além disso", "Ademais", "Outrossim", "Nesse sentido",
"Nesse contexto", "Diante disso", "Dessa forma", "Vale ressaltar", "Cabe
destacar", "Em suma", "Sobretudo", "Consequentemente". Ponto final e uma
frase nova resolvem melhor.

**Adjetivos vazios** — "excelência", "expertise", "know-how", "qualidade
excepcional", "soluções personalizadas", "altamente qualificado",
"atendimento diferenciado", "trajetória sólida". Troque por um número ou um
exemplo verificável.

**Venda genérica** — "você chegou ao lugar certo", "não deixe essa
oportunidade passar", "entre em contato hoje mesmo", "com anos de
experiência no mercado", "conte com quem entende". O convite ao serviço já
aparece sozinho no rodapé; o artigo não vende.

**Fechamentos** — "Em resumo", "Para concluir", "Portanto, não espere",
"Pronto para dar o próximo passo?". Termine com o último conselho útil, sem
despedida.

**Metáforas motivacionais** — "a jornada de", "desbloquear todo o
potencial", "elevar a um novo patamar", "revolucionar". O assunto é cortina.

**Palavras carimbo** — "robusto", "abrangente", "panorama", "vertente",
"fomentar", "engajamento", "peça-chave", "papel fundamental".

**Também fora:** emoji decorativo, trio de benefícios ("rapidez, eficiência
e qualidade"), três itens de lista seguidos abrindo com o mesmo verbo no
infinitivo, e voz passiva onde cabe sujeito ("são disponibilizados" →
"o fornecedor oferece").

## Tom

Escreva como quem já instalou aquilo e está explicando para um amigo que vai
comprar. Fale com **você**, não sobre "as pessoas" ou "os usuários".

Diga o que não funciona, inclusive quando isso reduz a venda. A frase
"mesmo que a compra não seja comigo" é o espírito do site inteiro: o texto
ganha confiança justamente por não empurrar.

Varie o tamanho dos parágrafos. Sequência de parágrafos com a mesma extensão
e a mesma cadência é o que faz o texto soar mecânico, mesmo sem nenhuma
palavra proibida.

## Estrutura

Alvo de **2.000 a 2.400 palavras**. Abaixo de 2.000 o artigo não passa na
auditoria do projeto.

1. **Abertura** (2-4 parágrafos) — a situação concreta, e a tese em uma
   frase. Sem "neste artigo você vai aprender".
2. **8 a 11 seções** com `##`. Título que promete uma resposta, não um tema:
   "Por que a barra escurece primeiro", não "Sobre a barra".
3. **Pelo menos uma tabela** comparativa. É o formato que mais ajuda quem
   está decidindo entre opções.
4. **Um passo a passo numerado**, quando houver procedimento.
5. **8 a 14 links internos** para outros guias e para as fichas em
   `/tipos-de-cortinas/`. Cheque os slugs: link quebrado reprova.
6. **"O que definir antes de comprar"** — lista de 10 itens acionáveis.
7. **"## Perguntas frequentes"** com 8 pares. O título exato importa: é ele
   que o site usa para gerar os dados estruturados do Google. Pergunta em
   `**negrito**`, resposta em 2-4 frases logo abaixo.

Não escreva assinatura nem chamada para WhatsApp no corpo. O bloco do autor
com o contato entra sozinho no rodapé de todo artigo.

## Como publicar

Escreva o corpo em `.md` e a ficha em `.json`, ambos no scratchpad:

```json
{
  "slug": "titulo-em-minusculas-com-hifens",
  "title": "Até 70 caracteres",
  "excerpt": "2 a 3 frases com o gancho concreto do artigo.",
  "metaTitle": "Até 70 caracteres",
  "metaDescription": "Até 170 caracteres.",
  "keywords": ["5 termos de busca reais"],
  "categoria": "guias-praticos",
  "tags": ["3 a 4 tags"],
  "coverImage": "/images/cortinas/persiana-rolo.jpg",
  "coverImageAlt": "Descrição do que aparece na imagem",
  "corpo": "caminho/absoluto/para/corpo.md"
}
```

Categorias: `ambientes`, `comparativos`, `conforto-e-eficiencia`,
`guias-praticos`, `manutencao`, `tecidos-e-materiais`, `tecnologia`.

Depois, nesta ordem:

```bash
npm run texto:auditar -- caminho/para/corpo.md
```

```bash
npm run post:criar -- caminho/para/ficha.json --rascunho
```

Sem `--aplicar` é simulação: mostra contagem de palavras, seções, tabelas,
links e FAQ, sem gravar nada. Corrija o que aparecer e só então rode de novo
com `--aplicar` no fim.

Ao terminar um lote, valide o conjunto:

```bash
npm run posts:auditoria
```

## O validador

`npm run texto:auditar` aceita três formas:

- `-- arquivo.md` — antes de publicar
- `-- --slug nome-do-post` — um artigo já no banco
- `-- --tudo` — o acervo inteiro

Ele conta os padrões da régua acima e explica o porquê de cada um. Sai com
erro se algo passar do limite, o que permite usá-lo em verificação
automática.

**Reprovar não é bloqueio.** Alguns travessões restantes no acervo estão em
pares de aposto, que é uso correto. O validador aponta onde olhar; a decisão
é de quem escreve. O que ele resolve é o ponto cego: ninguém percebe que
usou 21 travessões relendo o próprio texto.

## Antes de escrever um artigo novo

Confira se o assunto já não está coberto. O acervo tem 52 guias e 26 fichas
de tipo de cortina, e eles se citam entre si:

```bash
npm run posts:inventario
```

Se já houver um artigo canônico sobre aquilo, é melhor **ampliar** o
existente e linkar do novo do que criar um concorrente. Dois textos sobre o
mesmo tema dividem a audiência e se canibalizam na busca.
